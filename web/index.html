4Subtitle

Mau font lain (The Bold Font, Komika Axis, dll)? Install di komputer atau taruh di folder fonts\tambahan, lalu klik ↻.

Mesin subtitle

Groq menjalankan Whisper large-v3 di server mereka: clip 1 menit biasanya selesai dalam beberapa detik. Kalau Groq gagal/limit, KlipKu otomatis pakai mesin di laptop.
Contoh: kalau ditulis "Prasmul", hasil salah dengar seperti "plasmool" / "plas mul" otomatis diganti jadi "Prasmul". Tersimpan per channel.
Pengaturan lanjutan koreksi AI
API key Gemini gratis bisa dibuat di Google AI Studio. API key Claude dari console Anthropic (berbayar per pemakaian, terpisah dari langganan Claude).

5Judul hook paling penting — dibaca pertama kali

Tulis judulnya di kolom Judul hook (langkah 2). Pakai *kata* untuk menyorot kata dengan warna aksen, dan | untuk ganti baris paksa. Contoh: MOMEN *BANG WINDAH* MENEMUKAN PORTAL | DI GTA 6
💡 Bisa juga tarik judul langsung di preview (kanan) ke mana saja — otomatis pindah ke mode Bebas. Dekat garis tengah akan menempel sendiri.

✨ Judul hook dari AI (opsional)

Setelah subtitle jadi, AI membaca isi clip lalu memberi 3 pilihan judul hook, caption + hashtag TikTok, dan detik momen puncak (dipakai untuk intro kalau kolom intro kosong). Kalau judul di langkah 2 kosong, pilihan pertama dipakai otomatis. Di layar "Cek subtitle" kamu bisa pilih/ubah judulnya.

Intro hook + ulang dari awal

👆 kolom "⏪ Intro dari menit" di langkah 2 (misal 1:23:40). Kosong + Judul AI aktif = momen puncak pilihan AI.
