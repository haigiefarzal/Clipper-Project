1Bot Telegram belum

  1. Di Telegram, buka @BotFather → kirim /newbot.
  2. Nama bebas (misal KlipKu Agie), username harus diakhiri bot (misal klipku_agie_bot).
  3. Salin token yang diberikan BotFather, tempel di bawah.
Setelah token tersimpan: buka bot kamu di Telegram, tekan START, lalu klik Deteksi akun saya.

2Otak cloud (Cloudflare, gratis, nyala 24 jam) belum

  1. Daftar gratis di dash.cloudflare.com (tanpa kartu kredit).
  2. Buka My Profile → API Tokens → Create Token → template Edit Cloudflare Workers → Use template.
  3. Di bagian Permissions klik + Add more: Account · D1 · Edit. Account Resources: akun kamu. Lalu Continue → Create Token → salin.
  4. Tempel di bawah lalu klik Pasang otak. KlipKu yang membuat database, mengunggah otak, memasang jadwal 5 menit, dan menyambungkan bot.
