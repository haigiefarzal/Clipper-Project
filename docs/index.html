4Subtitle

Mesin subtitle

Groq menjalankan Whisper large-v3 di server mereka: clip 1 menit biasanya selesai dalam beberapa detik. Kalau Groq gagal/limit, otomatis pakai mesin di browser.
Model di-download sekali, lalu tersimpan di browser.
Kalau ditulis "Prasmul", hasil salah dengar seperti "plasmool" / "plas mul" otomatis diganti jadi "Prasmul".
Pengaturan lanjutan koreksi AI
API key Gemini gratis dari Google AI Studio. API key Claude dari console Anthropic (berbayar per pemakaian). Key hanya disimpan di browser ini dan dikirim langsung ke Google/Anthropic.
